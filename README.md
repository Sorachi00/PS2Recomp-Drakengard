## Fork of PS2Recomp focused on Drakengard


This project statically recompiles PS2 ELF binaries into C++ and provides a runtime to execute the generated code.<br>

<h3>Contribution</h3>
-Follow the steps of https://github.com/ran-j/PS2Recomp to setup the project <br>
-Be sure to use the <a href="https://github.com/Sorachi00/PS2Recomp-Drakengard/blob/main/tools/drakengard_merged.toml">.toml</a> and <a href="https://github.com/Sorachi00/PS2Recomp-Drakengard/blob/main/tools/drakengard.csv">.csv</a> file to recomp the game. <br>
-As I did with CdvdService, new code needs to mimic the <a href="https://github.com/ps2dev/ps2sdk">ps2sdk</a> code unless it requires an adaptation to work on windows. <br>
-Usage of AI agents is prohibit. You may use AI to gather info and so, but you need to understand what you are writing. <br>
